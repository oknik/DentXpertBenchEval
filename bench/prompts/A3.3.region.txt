区域词表：全口、头颅侧位、上颌、下颌、正面、前牙区、右侧后牙区、左侧后牙区、上颌前牙区、下颌前牙区、右上后牙区、左上后牙区、右下后牙区、左下后牙区。

判定规则：
1. 未见需记录的异常时，输出{"findings": []}。
2. 按区域定位，每项只包含finding_code和region_code，region_code为非空的中文区域名称数组，各区域须来自评价范围，只记录该范围内可判读的所见。
3. 同一类别合并为一条记录，region_code汇总所有相关区域，去重并按区域此表的顺序排列。同一区域存在多种类别时，分别记录在对应类别中。
4. 牙列或咬合关系按其涉及的区域记录；未萌出不直接等于阻生或萌出延迟，当前未见牙齿不直接等于先天缺牙，咬合关系未显示时不推断咬合异常。

涉及左侧或右侧时，均以患者自身的左右侧为准。

请仅输出一个合法JSON对象，按以下结构模板填写，不增加额外字段、说明或代码围栏：
{
  "findings": [
    {
      "finding_code": "<实际发现的正畸／发育异常类别>",
      "region_code": ["<评价范围中允许的中文区域名称>"]
    }
  ]
}
