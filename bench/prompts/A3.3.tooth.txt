判定规则：
1. 未见需记录的异常时，输出{"findings": []}。
2. 按牙位定位，每项包含finding_code和非空FDI整数数组fdi。指定牙位时仅评价这些牙位；全口时评价影像中所有可判读的牙位。
3. 同种类型的异常合并为一条记录，fdi汇总所有相关牙位，去重并按FDI编号升序排列。同一牙位存在多种异常时，分别记录在对应类别中。

牙位统一使用FDI整数，不加引号。恒牙仅限11–18、21–28、31–38、41–48；乳牙仅限51–55、61–65、71–75、81–85。

请仅输出一个合法JSON对象，按以下结构模板填写；将数值占位符替换为实际数字，不加引号，不增加额外字段、说明或代码围栏：
{
  "findings": [
    {
      "finding_code": "<实际发现的正畸或发育异常类别>",
      "fdi": [<FDI整数>]
    }
  ]
}
